# ТЕМП

Сайт магазина спортивной одежды на ASP.NET Core Blazor. Основная работа сосредоточена на главной странице: композиция из товаров вместо слайдера, закреплённая навигация, подборки одежды и большой фотофуттер с появлением при прокрутке.

![Главная страница](docs/home.png)

## Стек

- C# и .NET 10, Blazor Interactive Server.
- HeroUI Styles и Tailwind CSS 4, интерактивные компоненты на Razor.
- Локальные шрифты Unbounded и Inter с кириллицей.

## Запуск

Установите .NET SDK 10. Для пересборки стилей также нужны Node.js и pnpm.

```sh
pnpm install --frozen-lockfile
pnpm run build:css
dotnet restore TempStore.slnx
dotnet run --project src/TempStore
```

Сайт откроется по адресу http://localhost:5186. Готовый CSS включён в репозиторий, поэтому для запуска без изменения стилей достаточно двух команд `dotnet`.

При работе со стилями:

```sh
pnpm run watch:css
```

После изменения стилей пересоберите приложение, чтобы обновились отпечатки статических ресурсов.

## Проверки

```sh
dotnet build TempStore.slnx
dotnet run --project tests/TempStore.Checks
```

## Состояние проекта

Главная страница адаптирована для компьютеров и телефонов. Также есть страницы каталога, товаров, корзины и интерфейсы личного кабинета и управления магазином. Каталог поддерживает поиск, сортировку и фильтры; корзина сохраняется в localStorage.

Товары берутся из `CatalogService`. База данных, серверная авторизация, обработка заказов, отправка обратной связи и оплата пока не подключены. Формы и административные страницы представляют интерфейс будущих функций.

## Структура

- `src/TempStore/Components` — страницы, layout и компоненты.
- `src/TempStore/Styles` — исходные стили.
- `src/TempStore/Services` — каталог, корзина и уведомления.
- `src/TempStore/wwwroot` — изображения, шрифты, JavaScript и собранный CSS.
- `tests/TempStore.Checks` — проверки каталога и корзины.

Источники фотографий товаров указаны в `src/TempStore/wwwroot/images/products/sources.json`. Лицензии шрифтов находятся рядом с файлами шрифтов в `src/TempStore/wwwroot/fonts`.
